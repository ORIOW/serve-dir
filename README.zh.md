# serve-dir

把任意本地目录开成一个局域网可访问的 HTTP 文件服务器——脚本固定在一处，分享哪个目录都不需要复制脚本。

- **浏览 / 下载**：样式化列表（默认）或朴素原生列表，支持子目录导航。
- **多选打包下载**：网页端勾选文件/文件夹后点「下载所选」，服务端从 `/__download?names=…` 流式打 zip。
- **可选写入**：开启后 client 可用 `PUT` 上传（`curl -T file http://<host>:<port>/name.txt`）。**默认只读**，带路径逃逸防护与单次 1 GiB 上限。
- **GUI 小工具**：可**同时运行多个 server**（不同路径/端口），无控制台窗口，可收进系统托盘长期驻留。

## 文件清单

```
scripts/serve_dir.py        # CLI 版（GUI 复用其全部服务端逻辑）
scripts/serve_dir_gui.py    # GUI 主程序
scripts/serve_dir_gui.pyw   # 双击入口（无控制台）
scripts/win_tray.py         # 纯 ctypes 托盘图标辅助
SKILL.md                    # agent 侧技能参考
tests/                      # 回归测试驱动（见下文）
serve-dir-GUI-验证报告.html  # GUI 交付验证报告
```

脚本只有**一份**、固定在 `scripts/`，通过 `--dir` 传要分享的目录，因此**任何目录都不需要放脚本副本**。

## CLI 用法

```bash
python scripts/serve_dir.py --dir "<目录>" [--port 8080] [--host 0.0.0.0] [--plain] [--allow-write]
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--dir` | 必填 | 要分享的目录（绝对或相对，支持 `~` 展开） |
| `--port` | `8080` | 监听端口 |
| `--host` | `0.0.0.0` | 绑定地址；`0.0.0.0` = 所有接口（局域网可访问） |
| `--plain` | 关 | 用朴素原生列表而非样式化列表（多选下载端点仍可用） |
| `--allow-write` | 关 | 允许 client `PUT` 上传（默认只读；单次上限 1 GiB） |

启动即打印本机与局域网访问地址及写入状态。端口被占用或处于 TIME_WAIT 释放等待期时，绑定会明确报错退出（不会静默双绑定）。

## GUI 用法

| 方式 | 命令 / 操作 | 控制台 |
|---|---|---|
| 双击入口（推荐） | 双击 `scripts/serve_dir_gui.pyw` | 无 |
| 显式 pythonw | `pythonw scripts/serve_dir_gui.py` | 无 |
| 普通 python | `python scripts/serve_dir_gui.py` | 有，但会自动转交 pythonw |

「启动新服务器」时生效的 GUI 选项：目录（+ 浏览）、端口 Spinbox（1–65535，非数字/越界拦截）、允许 client 写入、使用 pretty 样式列表。

**多实例**：每次点「启动新服务器」都会按当前配置新增一个独立 server，运行列表逐行显示端口/目录/写入/样式/状态，可同时服务多个路径。选中行后：「打开浏览器」（或双击该行）、热切换该实例的 PUT 权限、「停止选中」；「停止全部」一键清空。每个服务器需要独立端口。

**启动行为**：主线程**同步绑定**端口（占用/重复/非法输入立即弹窗，不再假"运行中"）→ 后台线程服务 → 后台自检（不阻塞界面、直连不走系统代理）：确认应答来自本工具（Server 头），pretty 比对条目数、plain 探测首个条目。

**托盘**：关闭窗口（×）**一律**收进系统托盘——无论有没有实例在跑，都不会因此退出进程（首次收起有气泡提示）；左键托盘图标＝显示/隐藏主窗口；右键菜单＝打开主窗口 / **退出**（退出是唯一的退出途径：会停止全部实例并删除图标）。托盘提示实时显示运行中的实例数。托盘不可用（加载失败/非 Windows）时，× 刻意降级为直接退出——否则窗口消失后将无法从界面退出。

## 网页端功能

- **多选下载**：列表页每行带复选框；「全选」+「下载所选（N）」→ `GET /__download?names=<相对路径>&names=…`（URL 编码，可重复参数）；目录会递归打包；服务端做路径逃逸校验（`../`、绝对路径、跨盘一律拒绝）。
- **上传**（开启写入后）：`PUT /<相对路径>`，请求体即文件内容；父目录不存在会自动创建（限服务目录内）；越界 403、超限 413、成功 201。例：`curl -T 本地文件.txt http://<host>:<port>/上传名.txt`

## 端口占用与重启语义

- 套接字使用 Windows `SO_EXCLUSIVEADDRUSE` 独占绑定：**不可能出现双绑定抢流量**（旧版风险已消除）。
- 代价：刚停止后立即重启可能遇到 TIME_WAIT（约 2–4 分钟）报占用。等一会或换端口；GUI/CLI 都会给出明确错误而非静默异常。
- 占用探测以「能否建立连接」为准（真实监听者才接受连接，TIME_WAIT 不误报）。

## 测试

回归驱动位于 `tests/`，需从**技能根目录**运行（驱动依赖 `os.path.abspath('scripts')`）：

```bash
python tests/sd_fix_test.py       # 35 项（单实例）
python tests/sd_multi_test.py    # 23 项（多实例）
python tests/sd_review_test.py   # 15 项（评审修复）
python tests/sd_tray_test.py     # 16 项（托盘）
pythonw tests/sd_tray_pt.py      # 实机全链路；日志写 %TEMP%\sd_tray_pt.log
python tests/sd_pythonw_repro.py # 复现 pythonw 下 stderr=None 的 bug
```

预期每个套件都输出 `FAILED: none`。临时产物在 `%TEMP%\sd_*`。

> 托盘套件需要真实的交互式 Windows 会话：在无头/沙箱进程中 `Shell_NotifyIconW(NIM_ADD)` 会返回 0，因此托盘检查可能因环境原因失败，即使代码本身正确。

## 安全提示

- **绑定 `0.0.0.0` 即向局域网开放该目录**——分享前确认目录内没有密钥或个人文件。
- **开启写入 = 任何人可上传**——局域网上的任何人都可以覆盖文件或撑满磁盘（单次上限 1 GiB）。用完即关。
- 本工具**不做任何鉴权**，请勿用于生产托管或需要访问控制的共享。
